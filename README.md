# Juction Hardware - Asian Paints Dealer Website

A modern, responsive React website for Juction Hardware Stores, the official Asian Paints dealer in Chitwan, Nepal.

## 🎨 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive Layout**: Fully responsive design that works on all devices
- **Product Catalog**: Complete Asian Paints product showcase with filtering
- **Service Pages**: Detailed service offerings and pricing
- **Contact Form**: Interactive contact form with validation
- **About Section**: Company information and team details
- **SEO Optimized**: Meta tags and structured content for better search visibility

## 🚀 Technologies Used

- **React 18** - Modern React with hooks and functional components
- **React Router** - Client-side routing
- **Framer Motion** - Smooth animations and transitions
- **Lucide React** - Beautiful, customizable icons
- **CSS3** - Modern CSS with custom properties and Grid/Flexbox
- **Responsive Design** - Mobile-first approach

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd juction-hardware
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the website

## 🔧 Customization

### Update Business Information
1. Edit contact details in `src/components/Footer.js`
2. Update phone numbers in `src/components/Navbar.js`
3. Modify business hours in contact pages

### Change Colors
1. Update CSS custom properties in `src/index.css`
2. Modify primary, secondary, and accent colors

### Add Products
1. Update product data in `src/pages/Products.js`
2. Add product images and descriptions
3. Update pricing and categories
